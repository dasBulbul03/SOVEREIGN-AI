# Qdrant
- Qdrant is an open-source vector database and similarity search engine used to store, manage, and retrieve high-dimensional vector embeddings generated by machine learning models and neural networks

- Qdrant is an open-source vector search engine and vector database written in Rust that provides fast and scalable similarity matching for AI and machine learning applications. 

- Core ConceptsPoints: The basic unit of data in Qdrant, containing a unique ID, a vector (embedding), and an optional JSON payload.
- Collections: Named groups of points where all vectors share the same dimensionality and distance metric.
- Payloads: Metadata attached to vectors that allows for precise filtering alongside vector proximity searches.
- Distance Metrics: Mathematical ways to measure similarity, such as Cosine, Dot product, or Euclidean distance. [1] (https://www.geeksforgeeks.org/data-science/qdrant/)

- Key FeaturesHigh Performance: Written in Rust for low latency and reliability under heavy loads.
- Advanced Filtering: Supports structured payload filtering for hybrid search capabilities.

- Flexible Deployment: Available as a local instance, via Docker, or as a fully managed Qdrant Cloud service with a free tier.
